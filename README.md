# מערכת ניהול תלמידות – עלמא

מערכת PHP + MySQL לניהול תלמידות, מסמכים ושכר לימוד. הקוד בלבד – **אין במאגר נתוני אמת וסיסמאות**.

## מבנה
- `private/` – מחוץ לתיקיית האתר בשרת (`/home/almascho/private`). הגדרות, ספריות, אחסון קבצים, סשנים.
- `public_html/` – התיקייה הציבורית של האתר.
- `private/config.sample.php` – תבנית הגדרות. בשרת מעתיקים ל-`private/config.php` וממלאים סיסמאות (הקובץ הזה לא נכנס ל-Git).

## התקנה ראשונה
ראו `docs/install.md`.
